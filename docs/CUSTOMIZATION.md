# Customize the profile

Edit [the banner](../assets/profile-terminal.svg) and [typing header](../assets/typing.svg) to change the colors, copy and typography. Both use system fonts and support reduced motion. The [PNG fallback](../assets/banner.png) is a static export of the banner. Replace the README banner path with assets/banner.png if a static image is needed, and re-export it after design changes.

Move sections by moving their heading and complete marker pair together. Edit [the renderer](../scripts/markdown_renderer.py) for project card formatting and [the statistics module](../scripts/statistics.py) for metric styling. Add verified skills or social links to README.md and README.template.md.

For sidebar changes, open GitHub **Settings → Public profile**. Enter Krushna Kale as the display name and use your portfolio URL. A suitable bio is “Python Developer | Cybersecurity Enthusiast | Building secure tools and automation.” Add your location and social accounts if you want them displayed. Use **Customize your pins** on the profile for GitHub’s native repository cards.
